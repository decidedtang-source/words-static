# 可配置英文自动朗读与练习进度

用户确认范围：单词、英文例句 1、英文例句 2，多选并排序；中文不自动朗读。切换词卡和打开详情独立控制。保留布局、记录、FSRS 排期，保留 Git 回滚版本。

实施步骤：
1. 添加独立偏好和可取消的顺序播放队列，验证顺序、缺失内容、停止与旧回调。
2. 接入切卡、显示释义、词库展开、词典详情事件，与模块顺序/折叠/遮挡解耦；设置即时保存，可调整 0/0.5/1/2 秒间隔。
3. 添加当前范围已开始/总词数进度，以及当前待学新词/到期复习和本轮作答次数。底部保留进度和停止按钮，卡片和详情可手动重播所选内容。
4. 单元、浏览器与手机布局验证，独立审查后部署原 GitHub Pages URL，公网回读。

默认：继续在显示释义时读单词；切卡和详情自动播放默认关闭，由用户分别开启。三个触发器使用同一份内容列表和顺序；缺少例句跳过，不替换成别处的例句。自动朗读不会揭开遮挡。原本“词汇模块折叠就禁止自动读”的规则由用户此次独立配置要求替代。

进度条表示所选词表范围内已经开始学习的词数，不代表掌握率或本轮完成率。待学数量包含当前词，受每日新词目标影响，并随到期复习动态变化。本轮次数统计评分，撤销扣回。

发音偏好存在本浏览器 localStorage；学习记录仍在 IndexedDB，备份结构不变。联网声音仍需用户原有的明确选择。切卡、导航、关闭详情、手动播放、停止和隐藏页面取消旧队列；发音失败停止队列，显示状态并可手动重播。
