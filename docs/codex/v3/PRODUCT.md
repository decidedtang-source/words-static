# UI-V3 产品规格

目标：先完成可靠、轻量的背词体验，再递进到语境理解与语言游戏分析。依据是已接受V3，不再做两根独立长栏，也不先展示长篇教学说明。

## 唯一默认阅读顺序

1. 英文目标、已核音标/发音、醒目中文短义与搭配。无已核IPA明确缺失，不组合编造。
2. 当前语境对应的具体词典义项：词形/词性、中文教学摘要、源英文定义。短义与具体词典依据是不同层，不重复长段正文。
3. “本句先记 · 怎么理解”：短提示，原句及译文就近，明确生成例句/原文来源。与后续全流程解析不重复铺陈。
4. 默认收起的“展开更多词典释义”：展示当前包全部已核义项（含当前义项以保留词条完整性），说明范围，不声称穷尽词典。无需额外弹窗或多层展开。
5. 默认可读的4–5组完整递进分析和学习例句；保留Dictionary、Memory、Semantic Connection以及Syntax → Concept → Contrast → Language Game → English Neighbors → Pragmatic Action → Workplace Use。
6. 顶部常驻及底部双复制。顶部简洁，说明/失败文本在可见反馈区域，不能压住正文。

完整冻结样例为working definition：整词中文是项目组合解释；working绑定暂定工作基础义，definition绑定词语意义说明义。不可把working普遍翻译成temporary；不可把work、working词条视为同一个对象。

## 三种主状态与特殊状态

| 场景 | 默认行为 |
|---|---|
| 学习正面 | 仅英文目标、音标/播放/揭晓；DOM不得挂载中文、解析、语境答案或可泄答案的深析payload；揭晓前隐藏双复制区 |
| 学习揭晓 | V3全部层级；更多义项初始关闭；评分条沿用现有FSRS与事务 |
| 卡片详情/带cardId查词 | 同一V3渲染；顶部双复制，无评分副作用 |
| 通用词典搜索，无cardId/语境 | 不杜撰“当前义项”；按词性直接显示已选词典义项，缺语境时不生成本句提示 |
| 旧卡没有V3绑定 | 保留历史短义，标“历史教学释义”；当前义项显示“本句词典义项待核”，可展开已有源词典；已有已审简析继续显示，无简析则明确待审 |
| 新批次绑定断裂 | 构建拒绝；运行时异常保留完整旧bundle或明确降级，不用第一义项冒充 |
| 撤回/不存在cardId | 无正文/复制payload；历史占位保留ID与事件，不能自动跳到同形词 |
| 工程案例E缺证据 | 仅隔离测试/设计案例，不进入正式内容链，不假装术语已核 |

更多义项开合仅为当前视图状态，不进学习数据库。下一张卡、刷新、换revision恢复关闭；从查词返回同一卡同renderHash时恢复揭晓、滚动及开合。内容变化/撤回使旧状态失效，必须重新揭晓，不能用DOM可见状态直接触发评分。

## 易读性与设备

沿用冻结V3色彩/层级/布局，正式端可为原生44px触控目标、可访问性和安全区作必要适配，不能借此重排信息优先级。桌面中文短义最大，义项逐行左到右；不是整列词典与整列解析各自读到底。窄屏按同一语义顺序堆叠。

六个验收视口：Windows 1440×810；Mac 1440×900；手机390×844/844×390；平板820×1180/1180×820。另测320px窄屏、200%缩放、长英文/长中文。浏览器尺寸不等于实机平台认证。

正文约16–17px，手机不通过缩小到难读来塞首屏；长句自然换行。顶部栏不可遮锚点；底部评分不可遮最后一行或复制失败textarea；横屏手机优先压缩装饰留白，不能让双固定栏挤掉阅读区域。

## 接受标准

基础词义不依赖打开ChatGPT；对应源义项无需展开；其余义项可键盘/触控展开收起，内容没有丢失。长分析仍为手动复制，不发起模型API。复制不评分，展开不评分，收藏不自动加入FSRS。所有产品信息通过静态GitHub页面使用，不要求本机服务。
