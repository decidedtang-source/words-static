# 成熟词汇系统的完整路线与范围

V3先完成“看懂一个词→在当前句子中理解→能用出来”的核心体验，不能一次把所有个人词书、同步、日更平台都绑进去。

第三方功能证据沿用2026-10-31 [历史Web差距表](../review-2026-10-31/MAIMEMO-WEB-GAPS.md)，标SOURCE_DOC_ONLY；没有本轮重新登录验证，不声称实现墨墨同款算法或全部Web能力。下面是本产品独立优先级。

| 次序 | 目标/交付 | 当前情况 | 依赖/QA/回滚 |
|---|---|---|---|
| V3-1 | 语境词典+折叠+本句理解+完整解析 | 已接受设计，运行整合未做 | Task1–4；精确绑定/兼容，回退候选不清库 |
| V3-2 | 稳定复习与连续内容更新 | P1–P3基础已有，待V3验证 | Task5/6，Owner授权发布；不复制第三方算法 |
| P4a | 词条记忆历史与下次复习说明 | 有events/FSRS，缺词条级完整展示 | 只读原数据，与调度一致；撤UI不改事件 |
| P4b | 统一查词、结果类型与本地查询历史 | 已有词库/词典查询，未统一 | 保持同形不同ID；可清查询历史不清学习历史 |
| P4c | 词书、加入/暂停/恢复 | 日期批次/收藏不是完整词书 | 独立引用稳定ID；不以收藏自动创建排期；新增备份协议另设计 |
| P4d | 提前练习、每日目标与学习方向 | 有目标/队列，缺完整控制 | 先只读练习不改排期；中→英召回单位另决策 |
| P4e | 私有自编词/笔记、偏好、活动时间 | 未实现完整功能 | 私有草稿不进Git，后台时间不计；存储/导出单独合同 |
| 后续A | 自动跨设备进度同步 | 未实现；现有手工双备份 | 账户/冲突/加密/服务端与隐私另立项，不混入V3 |
| 后续B | 全离线缓存/大词典分包 | 当前不承诺完整离线 | 缓存版本/退役/许可与包大小另审 |
| 后续C | 定时持续更新/Notion连接器 | 既有任务保留，未授权切换 | 先人工批次测质量/耗时再定频率；Notion历史改造继续暂停 |

每个P4包需单独定义交付与Owner选择，V3通过不自动授权全部包。商业/团队/社交/硬件功能不是个人学习主线，延期。

## 工作量与Owner节点

Task1–5合计约4–8工程日量级（可复用现有代码，非交付日期承诺）；语义审阅/源缺口/实机设备与Owner等待单列。不按“每天自动产生多少词”承诺未经实测的频率。

已决：GitHub正式产品、V3视觉与折叠层级、Notion仅选词、完整方法保留。
待决：Task1–5实际执行指令、真实设备可用范围及实现验收、G2精确候选发布、之后哪个P4包。无需再问V3还是V1/V2。
