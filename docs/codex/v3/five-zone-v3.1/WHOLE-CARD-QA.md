# 整页分区生产与 QA：Owner范围纠正

状态：whole-card/1。后面“五区讲解”只是整张词卡的一部分；“分区评分”覆盖整张卡，不可把二者混同。此契约覆盖此前把词源可省略、IPA/附加例句不核验仍称完整的范围说明。冻结HTML的布局与控件不变。

|整页模块|生产要求|独立审核重点|
|---|---|---|
|headword 词头|音标、词性、核心义、搭配|来源、语音体系、短语宽式音标与单词词典音标区别|
|currentSense 当前义/拆词|语境义、适用组成词义|整体短语不能机械逐词推出，原基线拆词区不丢失|
|directExplanation 直接讲解|成熟、直接、具体的当前用法|新增理解，不重复中文释义|
|etymology 词源/演变|现代联系、有据历史、回到当前用法|来源和现代类比分开，组成词历史不冒充整个短语起源；必须实际检索|
|context 本句先记|英文原句、中文、当前理解|逐句一致，不捏造事实|
|additionalSenses 更多义项|真实不同的已核验义项/明确同族词|不重复已直接展示的sense，不冒充全词典|
|g1—g5 后方五区|保留五区全部教学任务|原五区100项判分继续有效，不能代替前区|
|examples 学习例句|所有可见附加例句与译文|自然、义项匹配、自编标记；不可直接继承未核验文本|
|copyPayload 复制负载|冻结原型当前约定：term与【深析】+term|四按钮精确负载、成功提示和失败手动复制；功能测试不由文本评分替代|

每个内容模块独立四维评分（准确30、完成30、易读25、增量15），每项0—4；各项>=3、模块>=75，无阻断问题才合格。客观短字段按准确清晰无冗余给分，不要求为了“增量”硬加解释。模块缺失就是缺失，不以其他模块高分抵消。不生成一个整页平均分掩盖问题。

三道门禁：1内容字段与证据完整性；2独立模块质量；3呈现和交互功能。每词8个全页补充模块加g1—g5，共13模块。5词共65模块，不把共用同一来源误算成独立事实证据。

执行：Research/Writer先列整页缺口，写entries和whole-card-supplement；独立Reviewer核对每个可见模块，写旧五区回执与whole-card-reviews。整页hash绑定entry、supplement及五区回执；任一改变必须重审。CLI默认验证整页；--zones-only只供后五区开发诊断，禁止构建页面。缺词源或整页回执时不得输出完整候选。

机器记录whole-card-report，来源与任务状态公开列出；原五区report只是子报告。六视口检查全量前区、更多义项、词源往返切换及来源、附加例句、上下双复制与拒绝降级、原ABC/五区顺序和不溢出。UI DOM/CSS不改。保留原有产品应用/FSRS发布另行门禁；静态原型能力通过不等于生产需求全部实现。

当前纠错不是给模板增加功能，而是补齐冻结模板已有模块。任何确实无法核验的历史断言应删除或明确限定；必要模块无有效材料则保持EVIDENCE_GAP，不靠一段“待核”冒充完整。
