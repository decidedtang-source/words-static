# 50条试产复查：完整输出与分区评分修订提案

日期：2026-11-03。状态：READY_FOR_OWNER_REVIEW / SPEC_ONLY / NOT_DEPLOYED。

这是对试产的诊断和下一轮执行契约，不是已实现的新流水线，也不自动批准50条内容。冻结版式及已登记模板不变。本文件优先澄清本批“通过”的含义；原审核回执保留作历史证据，不改写成新标准下的通过。

## 1. 检查结论与证据边界

检查对象：`content/trials/five-zone-50-20261103/` 的生成脚本、50条结构化记录、旧QA、审核回执；细读scope、accountable、proposal、work around、weigh up。没有在本次重新逐一核验66个外部来源，因此以下是产品完整性与编辑方法审查，不是全部事实复核。

旧的50/50 APPROVE只表示通过当时较弱的编辑规则。浏览器300格检查证明呈现与布局，不证明教学质量。当前批次应视为 **NEEDS_ZONE_REASSESSMENT**，暂停扩量，不能宣称“50条完整优质成品”。并非所有正文都差：scope的边界类比和工作/目标对照值得保留，work around的动作/办法和solve对照也有价值；应定点修复而非全部重写。

## 2. 完整输出契约：完整不是多写

每条交付一个可审查内容包：原cardId与授权语境、前区数据、五区正文、claim证据表、完整性表、分区评分、问题与修订记录、绑定内容/来源/规则版本hash的独立审核回执。

前区检查：当前义与语境一致；词性/中文/英文解释可追溯；原有适用的拆词义保留；桥接至少增加一个有用的用法说明，不能复制定义；本句先记简短明确；更多义项只包含实际不同且经过核验的相关义项。没有额外义项应记录“不适用/待补”，不能重复填充冒充完成。词源并非必需；没有证据就不编。音标沿用但未复核应单独标记，不冒充已审。

后区要求见下表。要求是审核问题，不是新增UI字段，不强迫每区四段、每区一样长或每词五个网站。

|区|读者读完应能做什么|最低教学证据|常见失败|
|---|---|---|---|
|01 先记住，再联系|用一个抓手想起当前义，并联系一个已知用法|一句核心抓手＋一个有效联系；类比不得伪装词源|只重译词义，或谈“记搭配更好”却没给联系|
|02 句法与概念|读懂本句关键结构，知道概念边界|定位真正影响理解的结构＋用白话解释它在句中表达什么|列词性和宾语术语却不解释意义；逐词无重点拆解|
|03 辨析与英文邻居|知道此处为什么用它、换邻词会怎样|至少一个相关近邻＋同一情境下的差异或可重叠范围＋自然搭配|选很远的词做容易的对照；只说A强调X、B强调Y|
|04 这句话在做什么|理解说话者此刻要推动什么，并接得上话|必要背景（原句给出/假设分开）→具体话语行动→原句措辞线索→自然回应与下一步|讲资料摘要；只贴“邀请/请求”标签；凭空推断冲突或批准|
|05 工作中可以这样说|在另一个相近场景正确使用|使用时机＋可直接说的英文与中文＋可替换位置或关键限制|换几个名词重复04；只给孤立例句；大量无关警告|

缺语境不得虚构为事实，可用明确标注的教学假设；五区正文不能N/A跳过。非必要词源/额外义项可N/A并说明，不扣教学分；必需证据不足进入缺口队列，整条不冒充完整。

## 3. 分区评分：5区×4项，逐区过门槛

每区分别按下列四项打0—4分，并附具体句子、判分理由及扣分点。这里的分数是编辑判断，不能表示学习效果百分比。

|项|权重|核对内容|
|---|---|---|
|准确与证据|30|当前义、结构、事实、推断边界和来源匹配|
|教学完成度|30|本区最低教学证据是否齐全，是否真的解释了为什么|
|易读易懂|25|先给白话结论、例子具体、术语解释、读一遍可跟上|
|信息增量|15|相对前区/其他区增加理解，无反复翻译和无关提醒|

锚点：0=缺失/重大错误；1=重大缺口；2=基本相关但需要读者自行补桥梁；3=清楚完成教学任务，只有轻微可改处；4=有具体证据说明解释精确、自然且高效。不能因无错自动给4。

区分=Σ(维度分/4×权重)。每区≥75且每项≥3；准确性硬错、伪造来源、隐私/引用问题直接阻断。五区全部过线、前区完整性通过、必要证据全覆盖后，整条才可进入候选。总分仅用于排序：01占15%、02占20%、03占20%、04占25%、05占20%，不能抵消任何区不及格。完整性另外计数：已完成必需项/全部必需项，缺项明确列出，不用总分包装。

审核者先用同一组好/中/差样本校准；同一维度相差≥2级则讨论证据，保留分歧，禁止直接平均通过。改过的区及受影响相邻区重审；hash变化后旧回执失效。

### 诊断示例：proposal的04（本次单人评分，未作独立批准）

原段从“讨论尚未开始”讲到“I'll read it and note my questions”，最后又提醒“仍未表达赞成”。有行动和回应，但没有解释原句为什么是在安排会前准备，且末句与02/03重复。

准确3、教学2、易读3、增量2 → 63.75，REVISE。旧整条89分不能覆盖这个缺口。这不是对全部50条的新评分。

建议改写〔基于原句的教学分析，回应自编，待独立审核〕：

> 明天要讨论这份方案，说话者希望大家先看过再来。Please review 是请对方审阅，before tomorrow's discussion 把时间要求说清楚；这句话是在安排会前准备。可以接：I'll read it tonight and bring my questions tomorrow.（我今晚看，明天带着问题来。）这样既回应了任务，也说明了准备如何完成。

保留该区标题与版式。只在03保留有帮助的“提案不等于决定”对照，其他区不反复提醒审批。例子可稍长，但每句有独立作用；不追求压到统一字数。

## 4. 可完整输出的生产流程

|阶段|实际交付物|阻断/恢复|
|---|---|---|
|S0 固定输入|cardId、原语境及来源类型、冻结模板版本、已有词典数据清单|禁止覆盖学习身份；选词失败停在输入阶段|
|S1 缺口规划|前区及5区各自的学习问题、必需证据清单、可复用证据|先明确需要解释什么，不能检索回来再硬塞五区|
|S2 定向取证|claimId、具体论断、sourceId、可见小节/定位、访问状态、证据摘要、适用范围|摘要不足以支持辨析就补查；不把搜索片段标为全文；同源可复用|
|S3 整理讲解|每区围绕自己的问题独立整理；事实/教学推断/自编例句分类|关键缺口留在队列，不用通用管理建议填满|
|S4 全卡编辑|前区、五区、完整性表、重复检查|删除无增量复述；必要事实保留；不得为了去重删拆词释义|
|S5 自动校验|schema、ID、引用解析、claim覆盖、重复、hash报告|机械检查只证明结构；不能自动写semantic PASS或stageCoverage完成|
|S6 独立分区审核|5×4评分、每项理由、事实核对、逐区问题与decision|Writer≠Reviewer；不达标只退回相关区和证据，禁止自行提分|
|S7 修订与封包|变更区、依赖影响、重审回执、最终可读页面|来源或正文变更使相关回执过期；无未解决必需项才成候选|
|S8 产品验收|原版式预览、真实应用适配、双复制/词典/FSRS兼容测试、Owner反馈|内容合格≠应用集成或发布；main/Pages另行授权|

状态按条/区保存：NOT_STARTED → EVIDENCE_GAP / DRAFT → REVIEW → REVISE / CANDIDATE。整批显示真实数量和未完成原因，不能仅显示“运行成功”。规则版本、输入hash、来源hash与区hash构成缓存键；中断后只继续未完成或已失效的项。相同缺口连续两轮无进展，标为BLOCKED_EVIDENCE/NEEDS_EDITOR_DECISION并给出具体问题，停止该条而非整批假通过。

检索材料完整阅读后做原创整理；不公开缓存受限全文。来源数量、正文长度不作质量替代指标。来源摘要与必要证据可复用，不能复用与当前句无关的结论；耗时/token没有实测时记unknown。

## 5. 实施次序、验收与回滚

1. **先校准5条**：scope、accountable、proposal、work around、weigh up。保留可用内容，按本契约出缺口表、20项分区评分及完整页面；独立复核并让Owner试读，不先扩到下一批50。
2. **实现可执行门禁**：新增版本化内容包/证据/分区审核schema及validate-only命令，保留旧试产格式。覆盖缺区、非空但教学项缺失、孤立claim、来源仅部分支持、重复更多义项、重复桥接、弱区被高总分掩盖、自审、旧hash、失败恢复等负向样例。文字语义不足必须由Reviewer给fail，脚本不能靠关键词替代阅读。
3. **完整跑通5条**：保存检索→生成→审核→退修→重审轨迹；故意中断一次验证恢复；显示单条缺口不丢其他完成项。对实际页面检查字典数据、五区内容及现有版式。不得宣称仅靠schema就已建成检索/生成自动化。
4. **分批修复原50条**：先修共享根因，再按10条一组复审；所有条目都需5区评分。不得把抽样结果推广为全批通过；完成后提供前后对照、分区分布、最低分、退修原因及剩余缺口。
5. **独立产品集成阶段**：内容稳定后再适配正式schema与真实应用，回归双复制和学习记录兼容。Owner确认内容和单独发布授权后才进入main/Pages。

风险：更细的表可能增加审核负担，表只供生产侧，不展示给学习者；门槛可能诱导填表刷分，必须给文本证据并留Owner反例反馈；自动检索可能失败，缺口显式阻断；为了完整可能膨胀正文，按教学增量而非字数验收。回滚：每批候选可独立撤销，保留旧数据及原审核记录；冻结HTML、正式内容与学习事件不随规划修订变化。下一轮工作流实现与5条校准尚未完成，本次不声称自动化已建成。
