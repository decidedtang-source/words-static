# 双模块词汇解释试验：A/B/C × 五类词的初评审阅

**状态：ASSISTANT_PRELIMINARY_REVIEW / NOT_INDEPENDENT_CONTENT_APPROVAL / NOT_DEPLOYED。** 研究入口：[TWO-PART-LEXICAL-WORKFLOW.md](TWO-PART-LEXICAL-WORKFLOW.md)。V3 原前半和 01–05 五区固定，A/B/C **只更换两个模块之间的独立语义桥**。

本轮在对话中生成了独立离线 HTML：五类词（含原 working definition）各有 A/B/C 三种桥，共**15 个不同内容候选**，可切换回忆正面、揭示、词典详情。HTML 在用户聊天附件中提供，尚未放入 GitHub Pages，也没有成为正式 v3 JSON/审核回执。

## 1. 测试纪律与结果

- 真实源：PR #5 的 OEWN 2025 精选 source metadata、五张现有 V3 已审候选的卡片释义/原句类型/五组正文；附外部 Cambridge、Oxford、Etymonline 证据链接仅供核对，不直接复制商业词典受保护正文。
- 五个案例每条均**保留原来的 01–05 五组正文**；A/B/C 只改变独立 Bridge 的教学入口、三个语义节点、解释、当前义及回句。
- Playwright Chromium standalone DOM test：1440、768、390、320px 四种宽度 × 五个案例 × 三种变体 = **60 次 Bridge 渲染/五区存在/横向溢出检查**；横向溢出 0、运行时页面异常 0；另测试折叠、背词正面隐藏/揭示、8 张桌面/手机全页截图。
- **局限**：页面用 page.set_content 模拟独立离线材料，不是 words-static 全套 FSRS/IndexedDB 真用户状态集成；未验证真实 iOS/Safari、屏幕阅读器、实际 ChatGPT 发送；也未经过外部独立语义 Reviewer 或真实 Owner 内容接受。
- 五区实际来源于 PR #5 候选的既有已审版本。本试验的新增 Bridge **没有继承旧回执的有效性**；以后改正式词条必须新 candidate hash、源证据、独立词义审核和版本化审批。

## 2. 评审方法

对 A/B/C 五维分别给0–5分，总25：
- SOURCE（来源/词义/词性/现代基本义与历史词源边界）；
- MEMORY（记忆锚点直观、可用）；
- BRIDGE（中间的语义关系自然、可解释）；
- CONTEXT（忠于原句的范围，不扩大批准/责任）；
- FIVE-AREA FIT（短而有用，**不重复/替代原 01–05**）。

**先硬审准确性**；来源、隐私、事实严重错误应一票否决，本次评分只是助手自评，不是独立 Reviewer 的事实证明，也不是自动算法客观测量。用户阅读体验/词汇熟悉程度仍可能改变推荐结论。

**这不是机械推崇 B**。词类不同、源证据不同，导致最好的桥接策略不同。

### A/B/C 的示范差别（重要，因为不能只改标题）

**SHIFT**
- A：当前被选中的 noun sense 已是班次，重点指出 before next shift 表示在下一班开始前。最短但不够帮助记忆另一个义项。
- B：现代 shift=move/change → 人员轮换画面 → 被轮换接替的一组人所工作的时段 → 原句。这是适当的语义助记，**不是已证的唯一词源演变**。
- C：古英语 sciftan 较早的安排/划分/分配含义（Etymonline），后来的移动/改变、十九世纪初工作时段义。准确但占信息量，默认桥里抢了轻便阅读功能；建议放词源旁注。

**WORKING DEFINITION**
- A：working 选用“暂定采用为工作依据”，definition 是概念界定，两者组合。
- B：想象缺陷分类讨论卡在标准不一致→先约定一个供工作进行的界定→该定义暂时可用、日后可修订；仍须把这个场景明确标成教学假设。
- C：Oxford/Cambridge 已将 working 修饰 theory/title/document/definition 一类用法解释为当前可用、尚有完善空间；适合来源核对，但不照搬其商业词典内容。

**OUTCOME FRAMING**
- A：frame 动词组织表述→framing 名词性核心→outcome 结果角度，依据主要 PR5 OEWN 现有组件证据。
- B：画框与取景焦点的类比，帮助形成具体印象，但更容易引发“画框一定是历史语义源头”的错误。
- C：Cambridge 直接有 framing 名词“如何表达/组织意义”的用法，选择它作为**外部核对**更能解决当前名词性用法的困惑；本项目不因此拥有 Cambridge 释义的再分发权。

**TAKE INTO ACCOUNT**
- A：整体短语已经有词典条目，直接从整体义到 take X into account 的结构与 X=测量不确定性。
- B：批准变更前考虑测量误差的工作情景。容易理解，但原第04区也谈同类评审实践。
- C：与 consider 近义对比，这应主要在原第03区，因此桥中重复。

## 4. 主要审阅发现和下一轮修改点

**发现 1：原第01区与新 Bridge 可能重复**。例如 shift 的 g1 本身又讲“班次、变化、换班”联系。由于这一轮保持五区逐字不变，桥在先、g1 在后可能有必要的重复。未来正式改版可在**保留五区结构和教学功能**的前提下，有选择地让 g1 更短、更偏记忆巩固；这属于新内容修改，必须重新审核 hash，不可借口“有桥了”删除 g1。

**发现 2：有些现代义的教学联系并非词源**。shift 的 move/change → rotating workers → work period 是自然助记；但 [Etymonline](https://www.etymonline.com/word/shift) 显示早期 Old English 表安排/分配等，具体早期工作班次义的过渡并非一条确定路线。需要标签区别“现代词义”“教学联想”“已核词源”。

**发现 3：framing 不应只凭 OEWN 组件硬推**。Cambridge 实际收录名词 framing 对表达方式/意义框定的用法（https://dictionary.cambridge.org/dictionary/english/framing）；PR #5 现有 OEWN 词典选的是 frame 动词义，因为它当时的精选 framing 名词词条不包含这层直对应。新内容应保留 OEWN 当下实际 refs，不伪装新义项已进入公开词典，也不偷复制外部词典正文。

**发现 4：习语不用强行造语源故事**。take into account 先整体记，再解释 take X into account 的句法槽位；这是高质量桥，不应被“每个词要追原义”的规则打成失败。

**发现 5：整句桥与原五区有分工边界**。条件式排程句桥中只说“计划的稳妥判断依赖前提”，五区继续处理 If/whether 结构、achievable/on track 区别和限制承诺，不让桥提前吃掉第02、04区。

## 5. 是否可以推进 PR5？

**目前不能作为新 Bridge 内容直接 APPROVE，也不能用于正式发布。**

本轮完成了 W0–W4（在现有安全教学示例基础上生成）和一轮**助手预审及离线浏览器模拟 UAT**。但 W5 的真实独立词义审核、W6 独立教学 Reviewer、将新 Bridge 加入正式静态数据模型、更新 reviewer receipt/hash、运行 words-static 实际 App 回归、Owner 真实设备/内容验收及正式 G2 都未完成。

**建议 Codex 下一步**：
1. 先按本表为四个不同类型词条挑 **B / B / C / A** 作为待审核候选；整句 B 做额外验证。
2. 分开存储现代基本义锚点、当前 sourceSense、语义教学联系与可选词源旁注；只公开可合法显示的数据。
3. 尽量沿用既有 V3 UI；新增一个**独立 unnumbered Bridge** 在更多词典义项之后，原五区之前。不要把 Bridge 挤入 g1 或砍掉五区。
4. Writer 重写需要改动的重复句后，交新上下文 Reviewer 核源、准确解释并签 exact hash。旧 v2 回执不能继承。
5. 在独立分支实际构建 PR 预览并检查所有模式和移动端，再由 Owner 决定是否授权发布。

**最终验收标准**：读者可以说出当前词最有用的真实基本意义；理解它与所选义项怎样联系；在原句中解释得通；随后依旧能完整学习五区内容，而不会看到一个漂亮但凭空编造的词源故事。
