状态：**Owner 教学风格建议 / 内容生产规范候选 / NOT_IMPLEMENTED / NOT_REVIEWED**。
本文件补充 [SEMANTIC-BRIDGE.md](SEMANTIC-BRIDGE.md)，**不得替换** V3 前半词典/本句区域，也不得替换原 01–05 五区。目标是让词义讲解更符合成熟背词书、学习词典“先理解、再联想、最后掌握具体用法”的阅读习惯。

## 1. 本次用户真正要求什么

**先知道一个词通常在说什么**，然后能用一个熟悉的意思联系另一个常见意义，再理解它在当前句子中的用法，而不是一上来就呈现几条正确却彼此孤立的字典事实。

对多义词，Bridge 的引导顺序优先为：

**可记的现代常用基本义 → 有证据或合理、明确标注的语义联系 → 当前语境所选义项 → 当前句法/用途 → 原五区递进分析**。

“基本义”“核心意义”“原意”在用户的学习表达中往往是**适合记忆的现代意义锚点**，并非严格历史语言学意义上的“最早记录义”。不要假装一个词必有唯一核心义，或所有义项都是从一个义项直接演变。

### 必须区分的三种陈述

1. **Dictionary sense / 词典事实**：权威、已核的某个词性和义项；可以直接引用已经合法收录的来源与 sense ID。
2. **Pedagogical bridge / 记忆性语义联系**：可以解释为什么 A 的意象有助于理解 B，但是**不是**凭这个意象就能断言历史上“先有 A，后来出现 B”。
3. **Historical etymology / 历史词源**：只有实际核实的来源能支持具体古词形、年代和语义发展的断言；词源来源与 OEWN 现代词典数据库是不同产品。

### 不用强制统一

对于有自然关联的词，解释它；对于关联不自然/证据不足的多义词，直接说“这两个意思分别记”；对于习语先给整体义，不强行从字面单词义制造推导。**连贯并不等于用虚构的故事把所有义项连接起来。**

## 2. 三种成熟资料如何启发页面（各自证据不同）

- [Cambridge shift](https://dictionary.cambridge.org/dictionary/english/shift)：按词性分开 change/move 与 shift noun（work period or workers），并给 *shift focus*、日夜班等使用环境。
- [Oxford shift noun](https://www.oxfordlearnersdictionaries.com/definition/english/shift_1)：把“班次/一组工作者”和“变化”列为**不同的名词义项**，辅以 night/day shift、work a shift、in shifts 等常见搭配。
- [墨墨超级释义官方说明](https://memodocs.maimemo.com/docs/AXhuwXpfFibceakKPpdc6VbVnFc)：支持“释义数量少/中/多”和“释义描述简/中/详”等偏好。此资料**没有**提供墨墨的 shift 词页或证实其曾采用下面这条语义故事，不能声称这是墨墨官方解释。
- [Etymonline shift 历史词源](https://www.etymonline.com/word/shift)：较早的 Old English **sciftan/scyftan** 包含“安排、划分、分配”等旧义；“改变”是后来有记载的动词义；名词“工作班次”记载于 1809 年，早期与矿业用法有关，可能受较早接力/轮换意义及其他日耳曼语影响。**词源存在不确定性时须保留 perhaps 等限定语**。

**资料结论**：我们可以用 **shift = move / change → 一组人轮换接替 → 轮到某组人工作的时间段 = a shift** 来帮助记忆“班次”；但这条箭头只能作为有实际语言联系的**教学解释路径**，不能被文案或 Reviewer 偷换成已经证明的唯一历史发展链条。

## 3. SHIFT 示例：更像成熟背词书的讲法

目标单词：**shift** /ʃɪft/ (US)；noun / verb。

**前半 V3 词典（保留现有设计、来源）**：
- 现代常用的记忆锚点：**移动、改变、转移**。*shift your position*（挪动位置）；*shift the focus*（转移重点）。
- 名词义 1：**变化、转变**，如 *a shift in priorities*。
- 名词义 2：**班次；一段当班时间**，如 *night shift*、*the next shift*。
- 当句所选 OEWN 名词 sense：**shift%1:28:00::**，英文定义 *the time period during which you are at work*。另有 shift 名词变化义、动词移动/转移义；不要把这些义项合并成一个官方词典 sense。
- 学习例句（项目自编）：*The supplier needs a work instruction before the next shift.*

**新增 Semantic Bridge（不编号，直接可见；建议正文）**：

> 先记 shift 最容易联想到的意思：**移动、改变或转移**。在生产中，工作由一组人员接替另一组人员，人员和工作时段会**轮换**；因此记忆时可以从“改变/轮换”联系到一个 **shift：轮到某组人工作的那段时间，即一个班次**。所以 *the next shift* 是“下一班次”，不是“下一次变化”。本句的 *before the next shift* 是要求在下一班开始前备好作业指导书，而不是指换班动作的那一瞬间。这是语义记忆联系，并非宣称单词在历史上必定按此顺序演变。

如果用户明确对 **“历史上最早是什么意思”** 感兴趣，可在可展开的词源补充里增加：

> 词源旁注：古英语 sciftan 原有“安排、划分、分配”等意思；后出现“改变、转移”等含义。工作班次义在 19 世纪早期已有记录。较老的工作轮换/接力用法与其历史关系并非简单的一条已确定的时间线。——Etymonline，具体链接见上。

**后面原五区完全保留**（本段只是内容示例；正式旧五区在未获批准时不擅自重写）：
1. **先记住，再联系**：当前句先记 shift＝班次，此外 shift 可以指变化/移动。一个班次是可确定的工作时段，不是换班动作本身。
2. **句法与概念**：*before the next shift* 是时间介词短语；shift 为名词，next 限定下一班；该句提出下班前文件需求，不给出具体时刻，也不证明文件获批准。
3. **辨析与英文邻居**：shift＝班次；handover＝工作/信息交接；changeover＝切换过程。night shift、shift supervisor、work instruction 等是生产准备讨论中的自然关联。
4. **这句话在做什么**：说明文件应在下一班前可用，可能引出版本、交接、确认等问题，但这些是实践推论而不是词典事实或授权。
5. **工作中可以这样说**：*Please confirm the work instruction before the next shift.*（请在下一班前确认作业指导书。）标明为教学句；confirm 的具体要求仍由场景确定。

**特别警惕“解释两次”**：Bridge 解释联系与由来；原五区 01 是简短**记忆归纳和区别巩固**，不复制 Bridge 的全部论证。原五区保持原职责与完整结构。

## 4. Writer 对其他词型的分流

- **多义词（shift）**：先有用的基本义/现代常见义，给一个具体例子；能自然联系则解释到当前义；不能则另记。
- **可组合词组（working definition）**：基本义锚点来自真正相关的组成词所选义项，解释它如何**作为一个整体**组合；不为 working、definition 分别生成完整桥/五区。
- **派生词（outcome framing）**：先识别 frame 的实际动词义、framing 的名词化角色，再解释 outcome 作为修饰语如何改变整个词组；不能把名词 framing 误认为进行时。
- **不透明习语（take into account）**：整体义已被词典收录时，先讲整体“考虑到”，无需从 account＝银行账户生造路径。
- **技术词/整句**：以真实问题/整句为分析单位；字典、语法和工程情境彼此区分，不强制解释每个普通词。
