## 2. 结论：讲解有价值，但实验工作台不能直接成为学习页

实例是有效的内容试验。B用场景联系词义，比机械拆词更贴合目标；五区也完整保留。但它不是经过独立事实审核或真实学习效果试验的产品成品。

### 明确发现

1. **研究操作占了首屏**。shift默认B，1440×810中文短义top=1262.9px；390×844为1777.0px。手机需要超过两屏的页面偏移才到短义。主要原因是案例选择、A/B/C选择、workflow、说明和自评分，不归咎于V3原词典区。
2. **桥太重且重复**。shift桥含标签/说明约480字符，手机约951.5px高。桥、三个节点、当前义、回句、免责说明、过渡指示与g1多次复述同一关系。此数值是可见文本/布局测量，不是阅读耗时或记忆测试。
3. **“无溢出”不等于好读**。五个测量视口横向溢出均false，但第一屏没有词义；手机桥正文CSS为14px，应该通过减少重复提升密度，而非继续缩字。
4. **箭头可能误导**。shift C以古英语→现代义→班次排成路径，即使正文说不确定，图形仍容易被理解为已证历史链。历史事实若不足，采用并列时间说明，不画确定因果箭头。
5. **情景越界与过度确定**。条件句B用“并不是问设备会不会伤人”过于绝对，应写“在这句排程语境里，优先理解为计划能否稳妥执行”；工作定义案例中的讨论受阻/标准不统一必须明确是假设场景。
6. **C不等于下一版C1**。现有C混合词源、词典来源核对、五区语法/辨析；不能整批改标签后当C1验收。outcome framing C正文还把Markdown的**标记作为普通文本显示，需消除格式泄露。
7. **事实审核尚未完成**。链接存在不等于每个主张已被它支持；网页自评24/25不能当独立来源审批。整个批次不应直接APPROVE。

## 4. 评分：先硬门槛，后100分质量量表

### 4.1 硬门槛，不参与平均

每条分别记录PASS / FAIL / NEEDS_EVIDENCE：

- 当前sense/POS/词形、词组整体义和原句范围正确；无虚构批准/技术事实。
- 每条词典事实/历史事实有可追溯支持；教学类比显式标识，不冒充历史因果。
- 来源允许对应使用方式；不公开私有材料；旧receipt不批准新桥。
- 原五区和原词典区不丢、不换序；切换/复制/展开不写FSRS事件，正面不泄答案。

任一FAIL阻断；NEEDS_EVIDENCE保持待核，不折算成0分掩盖不确定性。不能以高易读分补偿事实错误。

### 4.2 六维量表

统一锚点：0=缺失或反向误导；1=严重障碍；2=反复重读/操作才能理解；3=能完成但有明显负担；4=顺畅且有小缺点；5=本样本任务中简洁准确、无明显障碍。证据不足标NE，不自动给5。

| 维度 | 权重 | 核心检查及证据 |
|---|---:|---|
| 易理解 |25|读完能用自己的话说出本句义和联系，分清场景假设与事实；不得仅以“我觉得顺”给满分|
| 易读/定位 |20|短义首先可见，字号/行长/段落可扫读，手机不靠缩字；记录屏幕坐标、滚动和找信息任务|
| 可记忆设计 |15|一个有用锚点、自然具体场景；不强行把不相关义项串起来；长期记忆效果另测|
| 精简与分工 |15|桥解释联系，g1巩固；不复制原句/短义/五区；人工判断命题重复，文本相似度只提示|
| C1新增价值 |15|明确解决一个B未解决的词义/用法疑点，来源可核；不以长度或词典数量计分|
| 操作负担 |10|默认B即懂、原地切换/返回、焦点和滚动稳定，不挡评分/复制，不要求学习者操作研究面板|

总分=Σ(0–5得分/5×权重)。拟定验收：所有硬门槛PASS、总分≥80，各维≥3，易理解与易读≥4。此阈值是项目初始标准，应在小样本试读校准，不是行业标准。

无合格C1时允许B-only：C1维记N/A，显示“B-only，已评权重85”，按已评权重归一化，但不与B+C1总分直接排名。没有来源不要硬做C1。

### 4.4 用户学习评分与内容评分分开

## 5. 推荐产品设计

Owner已选B默认+C1可选；无需再次选A/B/C路线。技术呈现比较：

- 推荐：同一个独立桥，默认“词义联系”，有已审核C1时显示“深入词义”，点击在原位替换正文，可切回。桌面/手机顺序一致，符合已选方向。
- 备选但不推荐：B下方继续追加C1。上下对照容易，但更长、重复且五区更靠后。独立侧栏/弹窗在手机丢失上下文，也不采用。

页面阅读顺序：

```text
英文目标 / 发音 / 中文短义
当前词典义项 → 本句先记与原句 → [更多词典义项]
词义联系                       [深入词义]
  一个锚点 → 一个具体联系 → 本句义（允许只有两节点）
  2–3句自然解释；必要的“教学联想”短标签
01 先记住，再联系
02 句法与概念
03 辨析与英文邻居
04 这句话在做什么
05 工作中可以这样说
学习例句 / 底部双复制（顶部双复制继续保留）
```

**B内容预算是软目标**：正文约60–110汉字，复杂词组可至140；2–3节点不是必填模板，习语可一行整体义。手机桥目标不超过约450px（390×844、默认字号），不得通过裁切/小字达标。主正文16–17px，辅助来源13–14px，触控至少44px。原词典前半保持，不为塞桥强压原义项。

**C1**：约120–220汉字的2–3个短段，每条只解决一个疑点；简短结论→关键依据→回到当前用法。字数超标触发编辑复核，不自动截断。历史词源仅在可核且有学习价值时出现。资料不足时不提供活跃切换按钮，只简短提示“暂无已审核的深入说明”，B仍可用。

**来源展示**：事实旁有简洁出处入口；完整claim/source/rights账本在审阅侧。教学场景和联想的标签不能藏掉，但无需每段重复“不代表已获批准/不是词源”。涉及确切误解时保留一次就近边界说明。

**不新增设置中心**：本轮不加语言/字号/密度/记忆算法的多组偏好开关；保留浏览器缩放。C1选择仅内存视图状态；同卡同hash返回可恢复，新卡或内容变化归B，不能自动恢复过期C1。

**五区保持**：首个B/C1原型逐字保留原01–05以隔离变量；第二轮在保持编号、顺序和全部方法职责的条件下，仅对明确重复句做受审编辑。不要把词义桥塞进g1，也不对working/definition分别跑五区。

## 7. 内容生产与评分工作流

沿用W0–W9名称，但明确修订旧W4/W7，不再要求全部词生成三稿或选“赢家”：

W0选择授权目标/原句 → W1证据与使用权限账本 → W2当前义与现代锚点 → W3按词类选联系策略 → W4先写B，只有明确疑点且有来源才写C1（A可内部短基线） → W5独立事实review → W6独立教学review及量表 → W7同页B/C1桌面/手机试读 → W8严格schema/新hash与receipt候选PR → W9另获G2才发布。

最小角色：Writer、独立Reviewer、Builder/QA。Reviewer可一次承担事实与教学两张表，但必须与Writer不同上下文；高风险词源或专业词增加专门核源，不对每个普通词固定多Agent流水线。自动检查只能抓结构/权限字段/引用断裂/状态副作用，不能证明语义和版权正确。

每条评分记录：cardId、target/context hash、B/C1内容hash、源证据版本、reviewer、硬门槛结果、六维分与理由、设备/模式、拒绝原因、下一步。去掉固定填5的生成模板；NE和N/A必须可表示。

## 8. 最小架构建议与兼容

建议新增显式版本化的analysis v3批次（候选方案，不在本轮改schema）；v1/v2按原路径保留。桥是独立semanticBridge对象，含B、可选C1、当前entry/senseRefs、证据claimRefs和类型；不得占用displayGroups。refs区分本地已授权源义项与外部核对来源，不能伪造OEWN ID。
