**其他独立差距**：账号与跨设备学习同步、笔记/音频许可、离线缓存完整性、可访问性需要自己的需求验证；本次日志不足以证明它们在墨墨 Web 的具体行为，标 NOT_VERIFIED。Words Static 目前没有自动同步；先保留并说明手工备份。不得将“多设备能打开相同网址”描述成“学习进度已经同步”。

最高优先级是：可信基础词义与简析同页直显 → 经审内容能持续进入站点 → 词书/检索/个人复习控制。我们的十阶段简析是自有目标，不声称墨墨具有该方法。第三方日志仅作能力清单；本产品行为与验收由我们独立定义。无复制第三方词典数据、截图、代码或算法。

推荐次序 P1合同基础 → P2六组页面实现 → P3首批真实内容更新 → P4逐个成熟功能 → P5逐次获准发布。P4不是必须一口气交付的大版本；详见 [计划](IMPLEMENTATION-PLAN.md)。本轮只完成 P0 审阅与预览。
