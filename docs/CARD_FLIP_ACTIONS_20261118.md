# 个性化翻开动作与阅读连续性

用户要求：翻开单词卡可指定动作，例如自动揭开某一类遮挡。这里翻开指练习页“显示释义”。

实现计划：
1. 为五个主模块设置翻开时保持原状/展开/收起；为中文词义、基础词义、语境解释、英文例句、例句中文翻译独立设置是否自动揭开。
2. 默认全部保持当前行为。动作在恢复正面手动状态之后执行，明确选择的动作优先；没有选择的项目沿用正面状态与默认设置。仅改变当前词卡，下一张重新使用正面/默认设置。发音仍由独立的翻开自动朗读开关决定。
3. 设置内提供可操作的正面→翻开效果示例，预览和实际词卡使用同一应用函数。设置即时保存，存储被拒绝时提示本次仍生效。
4. 单元与浏览器验证：旧偏好迁移、独立揭开、展开/收起、预览不写偏好、下一张复位、刷新保留、手机布局。完整回归、审查、原址发布及线上验证。

追加需求：用户要求切词时正面↔正面、背面↔背面及正反面之间的阅读连续性。提供“切词保持当前面”可选项，默认仍先显示正面。默认按模块锚点衔接，分别记忆本轮正面/背面阅读位置；可选保留绝对滚动位置或回到顶部。增加返回正面操作，同一词正反面保留各自手动阅读状态，翻开时选定动作仍优先。新词重新使用默认显示设置，不继承上一词遮挡揭开状态；选择保持背面时，对新词应用翻开动作。下一词评分保存逻辑不变。

连续性浏览器覆盖：长文本且词义高度不同的卡片；正→背同模块视觉位置保持；返回正面恢复正面位置；再次翻开恢复背面位置；下一正面恢复原正面位置；开启保持当前面后下一背面按模块定位；兼容绝对滚动位置模式及320/390/768宽度按钮布局。

最终验证：29项单元测试、9组浏览器测试、构建及diff检查通过。全套回归曾捕获翻面误停正在播放的队列，已修正为仅在配置的自动播放触发时重启。独立审查发现返回正面按钮位于长卡底部、预览往返丢失手动状态，两个问题均用真实点击测试先复现失败再修复：返回正面移至固定操作区；预览保留各面的snapshot。手机320/390/768宽度操作按钮均可见、可点击。下一词默认仍先显示正面，保持背面需显式勾选；旧绝对滚动模式单独保留并回归。
