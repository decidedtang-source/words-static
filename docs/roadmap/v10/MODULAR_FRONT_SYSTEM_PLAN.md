## 生产与组装

只读原50词输入 → 模块生产器（固定资料获取与原创编辑分开）→ 各模块records和版本清单 → 核对ID/引用/依赖 → 合并字段 → 原主题/页面壳与各模块视图拼接 → 实际浏览器结构/流程检查 → 新目录试读。

每模块输出必须有moduleId/version/entryIds/inputHashes/outputHash。生产失败保留状态，不自动把一个模块的数据灌给另一个；拼接拒绝错词、缺模块、字段重复所有权和过期依赖。先建立流程、接口与脚本，再执行50词试生产；不把独立模块文档建立当作实际内容生产完成。

Etymonline直接HTTP现测403，不能假称独立HTTP抓取成功。实现可替换transport：直接获取/缓存/网页工具已取得的来源快照导入；解析与版本记录同一套脚本。快照导入明确记录访问方式；失败不伪装无条目。原始全文仅本地来源缓存，交付展示必要短引、中文资料整理及原链接，不复制整站。

七步延后状态写入本次scope。QA的七步字量规则仍为后续系统保留，但本轮记录not_in_scope/pending_build，不填pass；前部完成与全系统完成分别报告。既有V1.1规则不通过删正文或降低档位绕过。
