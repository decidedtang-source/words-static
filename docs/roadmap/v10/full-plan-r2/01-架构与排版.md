# 整体架构、排版与变更边界

版本随R2；本文件是方案，非已实现页面。模块详细行为见各自独立方案。

## 1. 页面从顶部到页尾

以下顺序来自实际V9 `word-page/shell.html`，保留不变：

1. **顶部来源折叠栏（M02）**：默认收起；展开看到原句、中文、来源、重点和必要限定。
2. **词头／音标／发音（M01）**：原字体、位置和控件尺寸。
3. **两个词义概览块（M03）**：左为精选常用义摘要，右为当前场景义摘要；点击定位，不切换互斥页面。
4. **完整词典入口（M04）**：在原位置，默认折叠；不把库存强制展开成首屏主体。
5. **精选常用义项＋例句（M05）**：每个义项独立解释、用法标签、例句、中文与来源。
6. **传统历史用法（M06）**：原独立区，不能归并进Bridge。
7. **场景学习（M07）**：原句、中文及必要上下文先出现，再说明当前义。普通正文位置仍在Bridge前。
8. **Bridge（M08）**：默认语义联系；下有独立折叠的历史联系；保留回看相关义项／传统历史链接。
9. **场景深入分析（M09）**：按七步方法自然组织连续正文，最后给原创工作表达。
10. **原页尾与返回（M03）**：既有锚点与阅读器内滚动。

M02与M07使用同一ContextUse投影，允许同句在不同阅读入口重复显示，不允许两份原句漂移。M05和M07可使用相同例句，但用途和来源必须正确；不能因“重复”而擅自删掉学习义项。

## 2. 阅读节奏与资料层次

第一层快速了解词头、常用义摘要和本句用法；第二层读成熟的精选义项与例句；第三层回到原场景，经Bridge进入原创七步。完整词典始终可独立查阅，不要求先读场景。当前义不在精选列表时，在场景／Bridge附近补充定位，不把整个精选区替换成场景答案。

完整词典以明确来源范围为“完整”的边界，不声称穷尽英语。全量库存、精选视图与当前语境三者独立，不能把一条旧教学库meaning同时当作三者数据。

前部英文例句优先成熟资料允许的短引或许可语料，中文释义／译文标整理。后部工作表达为原创，明确用途。真实文章、Episode、工作原材料和教学构造都可作为场景；非工作场景先按原情境理解，最后才做明确标注的制造业迁移。

## 3. 版式、导航与三屏

沿用 `word-page/theme.css`、`shell.html`、原模块view与behavior。基准包含浅／深色适配、Georgia词头、框架尺寸、字重、段距、侧栏和阅读器。禁止新建另一套主题、改变全页字体或把阅读器换成另一种滚动容器来“适配V10”。

- 手机：原宽度约410px的框架及内边距；两个词义块同排；概览滚出后出现原底部导航；保留底部阅读空间，不遮最后一行和控件。
- 平板：沿用约780px框架和扩大内边距；仍连续阅读，不新增分栏问答。
- 桌面：沿用左侧150px目录与主阅读列；桌面目录显示时不同时占用底部导航。
- 页面宽度390／768／1440是QA视口，不替代原410／780容器规则；320窄屏另作压力检查。
- 精选／场景按钮承载真实词义文字；长内容允许换行，不截断决定意义的否定或条件。不得改成空泛功能标题。
- 场景入口仍定位到原句 `wl-source`；兼容 `context→source`。词典／顶部来源链接自动展开对应折叠区。返回顶部回到当前词条，不切回目录或换词。
- 新七步保留 `wl-deep`；可增加文内轻量锚点，禁止强制A/B切换、七个等长大卡片或新增悬浮球。

上述是基准继承；若技术限制需要改动，先形成逐区差异和影响说明，更新方案后再批准，不能藏在sharedVersion中。

## 5. 后台职责分层

| 支撑部分 | 职责 | 所在方案 |
| --- | --- | --- |
| 输入与资料适配 | 原始快照、来源身份、许可与证据 | 数据接口、生产流程 |
| 词典／语境映射 | 源义项、精选、当前义与专业补充 | M04／M05／M07 |
| 分析与Practice | Bridge、七步、本地应用与共享实践 | M08／M09 |
| 审核与状态 | 作者／审阅者分开、失效、修订和统计 | QA、生产流程 |
| 内容包与静态适配 | 将已审数据投影到原九模块 | 数据接口、实施计划 |
| 版本与交接 | 方案批准、模块锁、发布与恢复 | 冻结同步 |

本阶段不新增服务器、账号、数据库服务或在线模型请求。数据模型可支持后续增量和多语境，具体在线服务另立方案，不由本轮静态阅读升级自动引入。
