# M03 · 词义概览、页内导航与返回

## 目的与基准

两个概览块同时告诉读者“通用意义”和“此处意义”，并能跳到正文。沿用 `word-page/modules/navigation/` 的 view、behavior、sidebar、bottom、footer及PROCESS；沿用阅读器内滚动，不新建悬浮球或另一套目录。

## 输入与输出

输入只读M05的 `general`（精选义摘要）及M07的 `meaning`（当前义摘要），外加实际可用锚点。不得再生成第三套释义。英文／中文摘要不同于词典官方定义时保留整理身份，语义与对应正文一致。

输出：两块实际词义、桌面侧栏、手机／平板滚动后的底栏、页尾链接、活动区标识。锚点保持 `top / dictionary / common / history / source / bridge / deep`；`context`仍别名到`source`，不跳过原句直达一个抽象释义块。

## 具体交互

- 左块保留通用／精选常用义内容和查看义项提示；右块保留场景实际解释和查看例句提示。无频率统计时统一标签“常用词义／精选常用义项”，在批准的文案差异表中登记；不可把块改成“查词典／看场景”空标题。
- 左跳common，右跳source；完整词典和顶部来源入口会展开目标details。
- 桌面原侧栏显示、底栏隐藏；小屏概览滚出阅读区后才显示底栏，不能在首屏同时挤两套导航。
- 返回顶部只滚当前reader到0；当前词、展开状态及学习数据不被顺带重置。切词取消发音并回到原默认顶部。
- Bridge回看相关义项可定位到稳定sense锚点；目标在折叠词典内时先展开，再定位，不靠数组序号假装永久ID。旧sense-0等锚点保留兼容映射。
- Practice链接是可选深读：返回能找回原entry/context和阅读位置；本页解释已足够独立理解，不要求先跳转。

## 缺失、版本与QA

未确定场景义不能由导航自动从通用义复制填空；制作端标阻塞，候选审阅入口可显示“当前用法待核实”，不可发布为已解释词条。可选历史没有内容时导航不得指向不存在节点；保留简短缺省区或同版本一致地禁用该项，方案选择保留区以保持基准顺序。

依赖M05/M07与M08锚点合同；只更正摘要时内容投影变，导航结构版本不必变。新增七步锚点仅在deep内，主目录不强增七个同权重入口。

QA `Q-N01`核对两个块的真实内容与正文；`Q-N02`遍历所有跳转、自动展开、回看、返回；`Q-N03`核对三屏侧栏／底栏互斥、长摘要、遮挡与键盘焦点；`Q-N04`查Practice往返及旧锚点。任何改成通用功能按钮或改变主滚动容器均属于设计失败。
