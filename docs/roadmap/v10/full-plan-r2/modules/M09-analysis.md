# M09 · 原七步分析与共享实践

## 目的与基准

V10后部按用户原方法升级，不再强保留旧五区的“先记住再联系”。沿用 `word-page/modules/analysis/` 的连续阅读语言和 `wl-deep`；只在该模块及必要数据适配处改变结构。原V9五区在旧发布目录不改。

## 输入与输出

输入当前ContextUse、合格Bridge、引用义项／专业证据、原Prompt哈希、可选Practice版本及depth理由。输出AnalysisRecord含七维coverage、自然段块、关系引用、2–5工作表达及译文／适用条件。某维未独立展开可标 integrated 或not_needed并写理由；不得用空字符串假装覆盖。

## 七维职责与先后

| 顺序 | 要回答的问题 | 不合格表现 |
| --- | --- | --- |
| Syntax | 本句中是什么成分、修饰谁、哪些结构决定理解 | 泛泛说“这是名词”，不处理关键否定／条件 |
| Concept | 当前具体所指、范围、适用判准 | 只重复中文标签或照抄场景摘要 |
| Contrast | 哪个邻近表达容易误用，什么时候换用 | 同义词列表，没有选择条件 |
| Language Game | 当前在什么活动中，谁有何角色，依据什么判断、什么回应切题 | 复制统一owner→due date→closure流程 |
| English Neighbors | 搭配、概念、问题为什么相连 | 无解释词云，或冒称统计频率 |
| Pragmatic Action | 当前说话者在请求／限定／澄清／提醒什么 | 将可能意图写成已发生结果 |
| Workplace Use | 在制造业沟通怎样自然使用 | 仅翻原句、无使用条件、示例冒充真实原话 |

数据保留七维顺序；显示允许合并相邻内容为自然小段，标题按解释重点，不强迫七个等长卡片。Concept须有本段新增解释，不能再次粘贴M07；Pragmatic Action不能重复Language Game同一句。导航只新增有价值的文内锚点，主区域仍是deep。

## 深度与技术概念

- 简明：直义、低歧义；压缩相邻维度，仍能解释当前用法及两句迁移，不为达字数扩写。
- 标准：有实用区别或实践规则；重点Contrast、Game、Neighbors，并交代边界。
- 深度：专业概念距离大、条件复杂或误用后果高；补现实问题、中文概念、反例及证据边界，英文术语随后绑定。
- 不按词长、原难度标签或token预算决定深度；深度理由独立保存。800／1800／3200只是原容量估算，不作输出配额，也不决定Bridge路线。

技术解释遵循现实问题→中文概念→英文术语→工程情景→工作表达，讲到理解与交流所需，不额外堆公式。非工作来源先尊重原语言活动，迁移至制造业须明确是新教学情境。

## 共享Practice完整合同

PracticeCard拥有id/version、典型情境、目标、角色与权限、关键概念、证据与判准、典型追问、可接受回应、边界／反例、来源及编辑解释身份。公共资料由单一合并者登记，不能多个词同时改同一版本。

一个词可关联零个、一个或多个Practice；不能强挂所有表达。每词保留1–3句本地应用，说明这个表达在此句如何进入实践。引用卡不是正文替代品，也不把整个共享卡复制到每词。Neighbors关系类型为collocation／contrast／required-evidence／role／typical-follow-up／condition，每条边附关系解释。

共享资料里的“典型”不是用户公司制度或逻辑必然；特别是授权、检验、放行和责任分配须保留适用条件。Practice改版触发实际引用它的条目重审，其他条目不受影响。

## 工作表达、版本与QA

每词2–5条短、自然、能在制造业项目沟通使用的原创表达，附中文、适用条件；可含回复句但不伪造原对话。包含条件时译文不得漏掉条件。不能以AI自评高分替代独立语义和语言审核。

接口v2明确替代旧memoryLink/interpret等五区字段，迁移映射只用于历史兼容，不机械把旧字段填成七维。视图局部升级；内容、Prompt、Practice、ContextUse或Bridge变化使对应审阅失效。

QA `Q-A01`七维作用、顺序及非机械展开；`Q-A02`三档与中文概念先行；`Q-A03`Game／Neighbors／Action分别增量；`Q-A04`多Practice、零Practice、版本与关系边；`Q-A05`2–5句自然英文／准确中文／用途／原创身份；`Q-A06`未见语境迁移和学习者试读。技术schema只能检查字段，不得替代这些语义检查。
