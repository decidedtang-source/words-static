# M05 · 精选常用义项与例句

## 目的与基准

这是前部成熟学习体验的主体。保留 `word-page/modules/learning/view.html` 中逐义项标题、标签、释义、英文例句、中文、来源及使用提示的结构。不是一条场景释义，也不能因试生产省事缩成“一个meaning＋一个例句”。

## 输入、选择与输出

输入LearningSelection：entryId、inventoryRef、selectedSenseIds、selectionReason、generalSummary、每义usage/example/translation/sourceRefs、note。输出原 `general / senses / note / learningSource` 投影，供页面和M03使用；检索时间、失败详情放编辑记录，正文只保留有用来源说明。

精选依据成熟学习词典的义项组织、学习相关性和真实资料；有真实语料统计才标“高频排名”，否则为“精选常用义项”。不强制每词同样数量：已有三词全部已核查精选义保留；新多义词通常选2–4个有教学价值的独立义（助手建议），单义或整体表达可以更少，但必须给选择理由，不能为达数量编义。

每个展示义项至少一个可用双语例句及用法说明；成熟来源许可不足时可用经过独立审核的原创例句并明确标识，不能冒充词典原句。不把同一句泛用例句套所有义项；同一语境例句与M07重复合法。

## 结构与内容边界

- 分开词性、可数性、搭配／介词和适用条件；CEFR等标签仅在来源确实给出时使用。
- 中文是理解辅助，不把宽义收窄成当前项目情景；当前句细节留M07。
- 使用小提示解决实际易错点，不写来源抓取日志或“审核通过”等生产状态。
- 原 `senses[].title/meta/en/example/zh/url/credit` 逐一保留／显式适配，不借新schema丢掉例句和来源。
- M03常用摘要从本模块精选结果派生；目录与正文共用同一经过审核的摘要，避免修正文却保留旧过强概括。

## 与场景、库存的关系

当前义不在精选列表时，M07选真义、M08补充定位；不强配精选第一义，不必因为一次场景就改变精选顺序。一般义、专业义和组合解释分别标识；原用户条目的meaning保留为原资料，改进学习释义写候选字段，不能回写原句或重建卡片。

## 版本与QA

精选增删或解释／例句变化提升内容版本并使相关语义审核失效；仅引用库存更高版本也需确认同义身份和限定未变。旧view默认不动，确需新增补充标记才局部版本更新。

QA `Q-L01`逐义与成熟来源、引用范围核对；`Q-L02`原三词义项数／顺序／例句／中文逐项对照，无批准删减为失败；`Q-L03`检查摘要／正文／导航一致及例句身份；`Q-L04`查场景义未覆盖时不强配、不伪频率。缺某精选义来源时退修该义，不悄悄把整个学习区降级为单义。
