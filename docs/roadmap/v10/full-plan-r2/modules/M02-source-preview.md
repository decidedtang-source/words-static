# M02 · 顶部场景例句与来源预览

## 目的与基准

保留用户“先知道摘自哪一句，再读场景义”的入口。沿用 `word-page/modules/source-preview/`；位置仍在词头前，默认折叠，锚点 `wl-top-source`。不另建第二份来源内容。

## 输入与输出

唯一上游为M07的ContextUse及必要显示投影：原句、中文、来源名称／日期／链接、引用身份、重点片段、当前义摘要和不可遗漏的限定。对外仍由scenario拥有数据；本模块只渲染，content中不存独立quote副本。

输出：收起时的“场景例句与来源＋来源摘要”；展开后同一原句、中文、来源与“此处重点”。导航定位此处时自动展开，普通换词回到基准默认收起。

## 展示与边界

- 与M07的原句和译文逐字一致；只允许布局／相同重点投影差异，不截掉否定、条件、主语或引语标识。
- 高亮只使用已确认span；词形变化要明确映射，无法定位就不高亮，不在原句里增词。
- 如省略上下文会改变含义，显示必要限定；延续absorb等例的否定上下文，不由“为了简洁”隐藏关键事实。
- 真实文章／Episode／工作记录／教学构造分别标识。来源链接未知可为空，使用明确的来源类别说明；不填假URL或假作者。
- 源页面暂无访问能力只在资料报告记详细错误；学习页保留简单而准确的来源身份，不能出现整段抓取日志。

## 生产、版本与QA

本模块无独立内容生成任务。M07原句、译文或重点变化时，本模块投影及显示需重验；相同内容在两处出现不是重复生成。来源为空时仍可读标为教学构造的原句；原句缺失时，场景型条目整体不具备启动分析条件，不能造句补位。

保留view／interface版本，只有展示契约真实改变才升级。`Q-S01`验证M02/M07原句、译文与来源身份一致；`Q-S02`检查默认收起、点击展开、跳转自动展开、重点及否定限定；`Q-S03`检查无日期／无URL／长句和陌生字符。验收失败回M07或渲染投影，不独自修另一份句子。
