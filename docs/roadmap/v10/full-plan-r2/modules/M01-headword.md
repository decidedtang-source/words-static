# M01 · 词头、音标与发音

## 目的与基准

让读者识别当前完整表达、词性与发音。沿用 `word-page/modules/headword/{content.json,interface.json,view.html,behavior.js,PROCESS.md}`。基准接口1.0.0；视图1.1.0。原44×44纯图标按钮、音波动画、隐藏读屏状态、减少动态效果偏好均保留。

## 输入、输出和归属

输入为当前entry/context身份及已核查 `word / ipa / pos`；显示仍投影到原字段。entryId不是词头字符串；短语用完整表达，不能自行截取其中一个词。IPA带口音／来源引用，来源管理层持有证据，不在词头堆审核日志。缺IPA时只隐藏音标值，不拼造音标、不把生成猜测标成词典音标。

输出为词头区 `wl-top` 和发音交互；不拥有场景句、释义、学习状态或语音文件下载任务。不因学习页音标校正改写原卡片ID。

## 展示与操作

- 原词头字体、字号、字重、词性位置不改。长短语自然换行，不缩成缩写。
- IPA旁按钮点击才发音；再次点击停止；切词、离页取消前一词发音，过期回调不能改变当前按钮。
- 保留V9明确选择本机 `localService` 美式英语语音的规则；无可用语音用title／隐藏读屏状态说明，不自动改用网络语音或浏览器默认远端服务。
- 播放／准备／结束／错误的可见变化仅限按钮状态或颜色／音波，不增加可见文字行；键盘可操作，aria-pressed准确。
- IPA与实际口音不一致时记录资料问题，不能用按钮存在声称字典真人发音。真实音质验收与模拟事件验收分开。

## 生产与失败

一般词IPA优先采用可核查词典条目；完整专业短语没有已核查音标可暂缺，不自动拼接成权威读音。资料层核对口音和词性后给此模块；新增词头内容版本独立变化。音频不可用不阻断文本阅读，但该条音频验收状态为不可用／未测，不能记passed。

## 变更、依赖与验收

本方案不要求重写view或behavior；仅内容适配和必要的来源字段留在外层合同。若发音逻辑确需修改，单独提升M01视图／流程版本并回归；其他八模块不因音标按钮改变而重写。共享主题保持原值。

QA：`Q-H01`查词头／IPA／词性与来源；`Q-H02`检查三屏播放开始／结束／错误／停止时按钮与相邻元素位移≤1px、无新增可见状态文字；`Q-H03`查无语音、快速切词、旧回调、键盘与reduced-motion。原三词和长短语压力案例都覆盖。失败只返修此模块或上游证据；不得借机重排页面。
