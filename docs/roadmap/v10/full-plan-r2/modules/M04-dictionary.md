# M04 · 独立完整词典系统

## 目的与基准

词典可独立查询，场景分析不能代替它。V9 `word-page/modules/dictionary/` 当前是折叠预留接口，非已接好的全量词典。本方案补齐数据和接口规划，保留 `wl-dictionary` 的原位置与默认收起行为。

## 数据输入与输出

输入SenseInventory：inventoryId、version、lexicalEntryId、adoptedSources、coverage、senses、usageLabels、phrases、sourceRefs。每个sense拥有本地稳定ID、来源senseID／定位、词性、原义说明、中文整理、用法限制及许可允许的例句。

输出是库存查阅视图和可被M05／M07／M08引用的义项，不是另一套场景文章。不同来源的近似义不自动合成一个义；本地合并必须保存各来源映射、合并理由和审阅。用户查整条短语时，组件结果分区说明“组成词”，不能登记为短语正式收录。

## 覆盖与展示

- “完整”指采用的指定来源／版本范围。某来源只有搜索摘录时只能做补充依据，不能标该词典完整库存。
- 默认折叠，展开显示词性→义项→用法／例句；英文定义配明确身份的中文整理，避免一大段无说明英文列表。
- 可在库存内标“精选学习采用”“本句采用”，这是引用关系，不代表真实频率。
- 释义较多时按词性／义项层级组织；不删掉库存义去凑首屏。重内容可按需加载，须提供成功／失败边界和本地预览离线产物；不得回到空壳模板。
- 已有可靠内容保留；新来源补充采用独立版本。旧学习资料与新库存不一致时列冲突交审，不静默改用户原词条。

## 接入与失败

先评估许可可用的离线词典、成熟学习词典及专业资料。当前已知仓库有OEWN选取资料，Cambridge历史记录含直接访问403；不能将两者写成可互换的完整学习词典。接入器输出归一化证据，再映射库存；模板不得直接读取供应商响应。

结果分为 complete_for_adopted_source、partial、not_available；含明确说明和版本。没有库存时保留原“完整词典待接入”级别的简短状态，不能用场景meaning顶替；精选区只要自身资料合格仍可独立成立。未具备完整库存不阻止有证据的场景分析，但本批完整词典覆盖率必须实报，不能称功能完成。

## 接口升级与QA

旧 `dictUrl/extra` 为兼容投影；新inventory引用由v2数据合同承载。先写显式v1→v2适配、保留旧页面，不直接把旧content解释成新结构。M04数据变化触发引用其sense的M05／M07／M08／M09重审，未引用义项不全库重写。

QA `Q-D01`核对源义、ID、来源版本与中文；`Q-D02`核对complete／partial真实及整体／组件区别；`Q-D03`核对默认折叠、展开层级、离线／加载失败；`Q-D04`核对映射变更、旧引用兼容与失效。词源由M06负责；词典中如有词源字段仅作为证据引用，不重复生成第二套历史。
