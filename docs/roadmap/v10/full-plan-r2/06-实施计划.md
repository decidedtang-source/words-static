# V10 全模块实施计划（冻结后执行）

> **For agentic workers:** 获得本方案具体版本审定、冻结及相应启动安排后，使用 executing-plans 按任务执行；不得因看到本计划而运行。所有任务框保持未完成。本轮只交付文档。

**Goal:** 在V9九模块及原学习身份兼容的基础上，实现可靠资料／场景／Bridge／七步内容链及可审阅候选，而非另建网站。

**Architecture:** 原始资料只读；版本化证据、义项、场景、原创分析与审阅分层；显式投影到原 `word-page/` 模块。写作与构建分离，构建不联网补事实。

**Tech Stack:** 延续Node、JSON、HTML/CSS/JS、现有测试和Playwright，不新增后端／数据库服务／付费API。

**Spec:** [R2总入口](README.md)、[数据合同](02-数据接口与依赖.md)、[流程](03-来源与生产流程.md)、[QA矩阵](04-QA矩阵.md)、[冻结门](05-冻结与同步.md)及九模块方案。

## 全局约束与实现顺序

原V9源码／固定页面、V6–V8、1875 ID与原句、FSRS／IndexedDB／备份不变；不动Podcast／日更任务。旧失配试样不成为模板或已审核内容。前部默认保留；任何主题／导航结构变化先登记方案差异，不由实现者自行决定。

前置顺序：F0/F1文档→F2用户审定→F3冻结→F4明确实施范围；完成必要实现和QA后，只有F4也明确包含试运行且相应校准门通过，才生成指定批次。实施授权和试运行授权可同一指令给出，也可分开；缺少的不能推定。

任务依赖：T0→T1→T2→T3→T4→T5→T6→T7→T8。T5模块内部可分工，但共享资源和锁由单一合并点管理；本计划不自动创建多代理或任务。

## Review Focus

1. 当前义不在精选常用列表：定位／补充真义，不把场景硬塞到常用第一义。
2. 自由组合与专业整体：允许有依据的组合解释，但不能从组件推出额外专业判准。
3. 有条件批准、否定、模态：全部限定保留，不产生原句没有的权限或结果。
4. 同输入改稿／同Practice改版：旧审核失效；复跑保留真实blocked/reviewed状态。
5. 新内容变长：允许后部高度变化，未受影响前部内容／排版／交互不被顺带重做。
