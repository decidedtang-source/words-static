# 前部资料自动接入 V2：实施方案

> For agentic workers: 使用superpowers:executing-plans按任务实施。用户已要求优化完整词典之外的模块，以脚本自动收集接入、AI整理为方向。

**Goal:** 将现有50词前部从固定编辑稿组装升级为资料采集、AI整理、结构化接入和可重复组装的流水线。
**Architecture:** 保留V1冻结文件；新增V2采集与输入合同，修改模块用独立版本文件接入，其余模块引用原实现。脚本保存来源快照、抽取原字段、生成AI任务包并校验回传；AI负责选择与当前义项相符的来源例句、中文翻译及场景／Bridge整理。
**Tech Stack:** Node.js、现有Playwright的惰性DOMParser、JSON、已有Open English Wordnet 2025快照。
**Spec:** 用户最新请求及MATURE_SOURCE_INTEGRATION_AUDIT_20261116.md。

## 确定范围与实现选择

- 完整词典M04不动；七步M09继续待搭建，不把本轮“其他部分”扩大为七步实现。
- 页面顺序、普通词史与Bridge折叠历史分开、原词条ID和原句不变。
- 选取已有成熟英文定义和例句；来源材料先保存，AI不重写来源英文后冒充原文。无合适来源用例时明确保留原创补充。
- 英语例句与中文翻译分别记录身份，AI选择绑定sourceExampleId与输入哈希；中文整理可以编辑，但不会覆盖原始材料。
- 优先利用已核实WordNet快照；学习词典补充采用Cambridge页面实际HTTP响应及DOM结构。2026-11-16实测capacity直连200，网页工具通路403；记录实际通路，不混称。
- Cambridge仅保存必要展示短引，来源页面原文及候选集只留本地缓存；释义可沿用已授权WordNet。完整词典接入不是此模块任务。
- 发音优先使用与所选音标一致的来源音频；未取得时沿用明确标识的本机TTS，按钮保持音波且不撑高页面。
- Etymonline先读取经哈希验证的已有缓存；可刷新请求并记录403，失败保留旧来源时间；实现HTML解析与工具快照导入两条明确通路。
- 场景采集只处理给定原文URL并定位原句；没有URL的50条教学句保留身份，不反向编造文章或作者来源。为后续真实场景接入提供同样的缓存接口。
- AI阶段以当前助手执行任务包并回传JSON为默认执行方式，不暗中启动模型API或声称无人值守调用已配置。
- 先同步本方案与流程，再运行新50词试产。新版本、新目录；旧V1及QA冻结不回写。

## 文件与模块职责

新增 `scripts/modules/automation/`：采集器、HTML解析、例句匹配、AI任务包／导入、V2组装与冻结CLI；新增`word-page/system.registry.v2.json`和有改动模块的`produce-v2.mjs`／视图文件。原M04直接复用同一生产器和视图。

原始缓存、完整候选任务在`local-evidence/automation-v2`；公开的选用资料、AI整理产物在`content/module-inputs/front-50-auto-v2`；试读在新`content/module-runs/front-50-auto-v2`。每条来源记录URL、获取方式、状态、原始hash、解析器版本；刷新失败另存尝试记录。

## 实施任务

### T1 采集与提取

- [ ] 先写测试：排除同义词集合中不含目标词的例句；词性／英美音标选择；HTTP403保留有效缓存；HTML仅提取目标条目；没有原文URL不冒称抓取。
- [ ] 实现版本化来源缓存、Cambridge/词史/场景解析入口及WordNet字段消费。网络有超时、并发上限、失败回执。
- [ ] 用真实capacity页面验证解析并保存小型合成回归夹具；不以真实全文进入测试仓。

### T2 AI任务与模块接入

- [ ] 先写测试：AI不能换原英文、不能用其他词任务的候选、输入hash变化使回传过期；原创补充与来源例句分别标记。
- [ ] 脚本生成任务包，AI只回传候选ID、译文及编辑字段；导入后解析为独立模块输入。
- [ ] M01接音标／发音；M05接来源例句和翻译；M06接共享词史；M07/M08接AI整理和来源引用；M02/M03仍只引用数据。

### T3 冻结、试产和同步

- [ ] 固定V2生产脚本与输入合同，保持V1／旧QA锁通过；同步产品与Hub。
- [ ] 运行50词收集→AI整理→接入→组装；实际记录来源例句／原创补充／音标／音频覆盖，不用流程通过代替接入覆盖。
- [ ] 检查页面原布局、发音高度、词典不变、原句不变与可重复生成。一次独立实现复查，只看结构流程问题。
- [ ] 输出本地直接可读页面与覆盖报告，同步GitHub；不部署。

## 检查重点

身份错配、旧缓存伪称新抓取、同义词例句误挂当前词、AI篡改来源英文、来源失败造成整批断掉。检查这些可编程结构／流程条件，不加入逐词语义评分，也不为篇幅或“稳妥”删减解释。
