## 复用流程

1. `node scripts/basic/freeze.mjs`验证冻结。
2. `node scripts/basic/collect.mjs`采集新增词典候选；Etymonline网页工具快照归档到local-evidence/basic100。
3. AI按来源选择义项和整理中文，产出content/basic-release-20261117/additions.json。固定输入供重放；修改输入须新建版本。
4. `node scripts/basic/build.mjs`校验来源与输入，组装、逐词检查后输出版本页面和release.lock.json。

AI任务仍由助手执行，不是无人值守模型API；词史网页工具补采不是HTTP直连成功。下次新增批次需新清单、新输入版本，不覆盖这次正式冻结。
