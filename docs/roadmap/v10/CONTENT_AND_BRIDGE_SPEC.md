# V10 义项、Bridge 与七步内容合同

状态：下一版规划，不是已运行的生成器。用户原始方法保存在 Context Hub：`projects/0003-work-english-podcast/reference/prompts/WORK_ENGLISH_SEVEN_STEP_USER_ORIGINAL_20261116.md`。不得用此适配规范覆盖或改写原 Prompt。

## 1. 两个独立判断：先找义，再决定怎么连

“常用义项是否收录”与“Bridge 怎么解释”是两个维度，不能混成一个四选一标签。

**义项定位结果**至少区分：已在精选列表；在已验证库存但未精选；来源支持的新补充义；原有义项的语境具体化；固定／组合表达整体解释；证据不足。

**联系策略**至少区分：直接适用；保留一个特征的语境具体化；有依据的现代语义联系；仅供记忆的类比；必须补充专业概念；不宜从已有常用义推导。

同一专业用法可以同时“补充义项＋关联普通义＋说明不能完全推导”。不要求某一标签包办全部说明。

## 2. 精选学习义不是意义全集

常见词 ≠ 常见义项 ≠ 当前最有学习价值的用法。没有语料统计就记录编辑选择理由，不制造频率排名。完整库存只声称覆盖明确的已采用来源版本；未获许可的数据不因为能搜索到就能整批复制。

当前用法必须由原句和上下文决定，不能为了套上精选义项而改原句。保留否定、模态、条件、引语身份以及是否为教学构造。截取 `absorbed the tariffs` 不能丢掉原句的否定。

组合型术语先判断整体，不能强行逐词拼装。例如入口应是 `entrance pupil`，不能把 `pupil = 入瞳` 写成普遍可替换词义。自由组合未被词典独立收录时明确标为组合解释。

## 3. Bridge 路由与面向学习者的正文

### A. 当前义已在精选列表

直接定位相关义项，只说当前句把对象或范围具体化为何。不要重复整段词典定义。

教学示例：scope 的范围义 → 项目约定的工作、交付物与排除项。Bridge 说明范围由已有约定界定，不自动推断说话者已经拒绝请求。

### B. 已有库存义未在精选列表

补充显示“本句补充用法”，引用真实 sense ID；不必更改精选排序。再判断与读者已知义项有没有有用联系。

可用文案：“前面的常用义项没有列出这里的用法。本句的 X 指……。它与 Y 共享的是……；但这里还需要注意……。”这是可选表达结构，不要求逐词重复此模板。

### C. 库存缺义，但来源能确认

先核实并增加有独立依据的义项或术语，再生成 Bridge。常见义能提供理解入口则解释联系；没有可靠联系则直接教专业概念。不得让模型先编一条桥，再倒找资料证明。

教学示例：`entrance pupil` 需要光学术语定义；可检查 `pupil` 的瞳孔义是否提供理解入口，但“学生”义不是必经起点；普通瞳孔义也不足以自行推出入瞳的成像定义。专业事实在正式入库前须另经权威资料核查，聊天示范不算生产证据。

### D. 不是新增词典义，而是当前语境具体化

只记录 ContextUse 并指向原 sense。某次会议中的 ownership 具体指测试异常跟进，不为每一种任务新增一个 ownership 词典义。

### E. 固定／制度／专业表达不可组合推出

先给整个表达的成立条件，再解释有限联系。`casting vote` 可联系 `cast a vote`，但“用于处理平票”等制度含义不能由两个单词的常见义独自推出；实际权限取决于适用制度，不能一概假设主席必有同一权限。

### F. 证据不足

记录 unresolved、缺什么证据以及已检索范围；不生成看似确定的解释，不纳入验收发布。允许别的词条继续生产，但不得把未决项隐藏成完成。

## 4. Bridge 的效果与禁止项

一条合格 Bridge 要让学习者知道：本句用的是哪个表达／义；可从哪个已知意义进入；保留了什么关系；哪里不能靠联系推出。简明句不要求复杂桥。

现代语义联系、记忆类比、历史演变三者分别标明。没有史源不说“这个意义就是这样演变而来”。学习页展示必要的边界说明，编辑过程／检索失败日志留在资料记录，不塞满正文。

不为追求统一强连所有义项；不把词典补充、场景解释、语用推论混写；不因语用分析需要就推断已批准、已承诺、已完成等事实。

## 5. 原始七步法，不再套旧五区

顺序：**Syntax → Concept → Contrast → Language Game → English Neighbors → Pragmatic Action → Workplace Use**。

- Syntax：抓影响理解的主干、词性、修饰与结构；缺原句时承认无法精确拆解。
- Concept：解释当前所指、范围与适用判准，不重复中文标签。
- Contrast：仅比较会改变理解或实际表达选择的近邻，给自然使用条件。
- Language Game：说明活动、角色、规则、问题、证据和什么回应算切题；不是把所有表达都改成项目流程图。
- English Neighbors：分清搭配、近义／反义、概念邻居、典型追问；说明为什么相连和讨论可能如何展开。
- Pragmatic Action：分析当前说话者做什么，区别句义、可能意图、对方实际回应和已发生后果。
- Workplace Use：2–5 个短、自然、可迁移的制造业工作表达，给必要中文解释；非工作原句先尊重原情境，最后才做明确标记的工作迁移。

七步为完整分析工具，不要求机械写七个同样长度的标题。简单词压缩、易混词突出 Contrast、工程普通词突出 Language Game／Neighbors、复杂句先 Syntax。数据可保存七个维度的 coverage 状态及未展开理由；不为通过 schema 空填七篇。

“维特根斯坦式”是受语言使用与实践启发的教学取向，不把这套七步归称为哲学家本人的固定程序。

## 6. 三档深度与单位

初始容量规划：简明 560、标准 940、深度 375，共 1,875。约为 30%／50%／20%，不是硬配额；按歧义、实践复杂度、误用后果和迁移价值分档。原“核心／提升／挑战”标签保留，但不直接等同深度。

每语境正文预算参考 800／1,800／3,200 输出 tokens，共约 3,340,000；只是规划参数，不是实测、不含输入、工具、推理、复审。额外语境另外计数，也不换算成 Pro 固定百分比。
