# 同尺寸正反面与独立内容

用户进一步明确：用正反面同尺寸解决翻面连续性；正面同样大但内容可以留空；正反面各自选择显示的模块。此要求优先于上一版分别恢复正反面位置的翻面逻辑。

计划：
1. 正反面各支持五主模块多选，可全部不选。旧单模块正面迁移成单元素选择；旧背面继续全显示。原快速单选仍可一键设为唯一正面。
2. 两面共用完整模块位置；未显示模块保留空间但不可见、不可聚焦、不进入可访问树。离屏测量两面折叠及翻开动作后的高度，预留较大值；同词手动展开后保持已用高度，避免返回时缩小。
3. 同词翻面保持当前滚动位置；切词仍尊重已有切换选项。新词重算尺寸，屏幕宽度变化重新计算。隐藏内容不触发播放，不添加学习事件。
4. 预览采用相同内容选择与等高逻辑。验证多选、留空、旧配置、可见性/键盘、翻面高度与位置、长文本、展开、手机宽度；完整回归、审查、发布。
