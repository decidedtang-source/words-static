用户确认：修改每日新词目标、切换单日或多日范围，两者都必须联动待学/已学。参考墨墨清晰的新学/复习任务呈现，提升动力；继续保留不限量及当前排期算法。

依据：墨墨官方每日学习量说明 https://memodocs.maimemo.com/docs/PulqwOB1xi5jV0kb8Y1cPE7ZnKc/ 说明其默认先复习再新学。这里只借鉴任务分类与反馈，本站每日新词目标仍按已有语义执行，不改成墨墨的总学习量，也不引入其收费上限。

计划：
1. 纯函数计算所选范围待学新词、到期复习、今日新学/复习去重词数、累计已开始、当前新词计划及全站新词额度。撤销不计、重复不增、已读不计，台北日界线一致。
2. 首页支持直接编辑每日新词目标/不限量，即时保存；选择日期即时刷新反馈；按真实成功保存状态开始学习。明确范围和每日全局额度，避免调目标伪造已学数。
3. 首页及背词页使用同一统计口径，显示新词进度条、已练次数与剩余任务。到期复习单列，不把重复练习包装成新词或掌握率。
4. 单元及浏览器回归：不同目标、0、不限量、单/多日期、撤销、跨日、目标保存失败/竞态、手机布局。审查、部署、线上验证，保留 Git 回滚标签。

计数：今日已学是当天评分过的不同词；今日新学是首次评分发生在今天；今日复习是此前已学的词今天再次评分，重复只计一个词。新词进度分母=本范围今日新学+当前实际可排入的新词数量，随目标/范围变化；全站每日已新学/目标另行标明。到期复习数会随时间变化，不用它构造会倒退的完成率。
