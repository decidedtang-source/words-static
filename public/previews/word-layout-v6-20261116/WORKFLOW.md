# v6 内容生成与资料获取流程（冻结于 2026-11-16）

这是用户确认冻结的三词阅读试样及实际制作流程。不是全量词库生成器，也不是成熟词典 API 已上线的声明。

## 内容职责

- 前部常用义项、例句、搭配、语法提示优先使用已有成熟词典资料；精选常用义不声称语料频次排名。完整词典仍是预留接口。
- 独立历史用法在前部常用学习之后。历史事实有出处，资料空缺如 absorb 成本义的年代不得补造。
- 场景原句必须保留来源、必要上下文与否定等限定。scope 当前是自编工作场景；leverage、absorb 是文章短引。
- 同一个 Bridge 默认显示通用义到场景义的连接，内部折叠历史联系；不拆为两种备选版，不替代前方历史用法。
- 五区连续分析是我们自己的核心内容与方法。顺序固定：先记住再联系 → 句法与概念 → 辨析与英文邻居 → 这句话在做什么 → 工作中可以这样说。可以核查资料，但不能用网上片段拼成五区或冒充词典原文。
- 此次仅冻结现有呈现与数据，不追加改写五区正文；上述职责澄清是后续生成的约束。

## 当前实际资料获取流程

1. 按单词查 Cambridge 官方词条，记录具体义项与例句归属、链接和日期。
2. 直接打开失败时如实记录 HTTP 状态；本次通过搜索索引读取官方词条正文，不绕过访问限制，不声称全文实时抓取成功。
3. 选取少量已核对原例句，逐项保留来源标签；中文释义、翻译标为整理。完整词典未抓取。sources.json 保存本次出处与限制。
4. 历史资料独立核查；场景原句区分原文、节选、改编、自编。正文可短引，不整篇复制。自动采集或全量集成另按来源允许的方式实施。
5. 人工/助手整理 data.json；Bridge 校验相关义项、场景限定、连接依据及历史证据。五区按我们的连续分析方法撰写，分析判断不能标成来源事实。
6. 已核对数据进入离线生成。生成阶段不访问互联网、不自行改写或刷新内容。

当前流程需要在线检索和人工核对，不存在已完成的自动抓取器、定时刷新、全库质量保证或 API 密钥。

## 可复现构建

在仓库根目录执行 `npm ci`，浏览器使用 Playwright Chromium（`npx playwright install chromium`）或设置 CHROMIUM_PATH；Windows 默认可用 Edge。

```text
node public/previews/word-layout-v6-20261116/build-preview.cjs
node public/previews/word-layout-v6-20261116/check-preview.cjs
node public/previews/word-layout-v6-20261116/verify-freeze.cjs
```

build-preview.cjs 从 data.json + template.html 生成独立 index.html，包含默认词条的静态回退。check-preview.cjs 检查三个词在四种宽度、三种屏幕选择下的结构、折叠、锚点和溢出。来源事实质量仍需内容核对，浏览器测试不能替代。

PDF：运行 export-pdf.cjs 生成六个长页，再用安装了 pypdf 的 Python 运行 combine-pdf.py。前三页默认折叠，后三页展开 Bridge 历史联系。重生成 PDF 可能因元数据或字体环境产生不同字节；发布版 review.pdf 的哈希以 manifest.json 为准，不能静默覆盖冻结版。

## 冻结与发布

index.html、review.pdf 保留用户看到的 v6 原文件。manifest.json 记录本包 SHA-256。版本发布到 /previews/word-layout-v6-20261116/；后续修改使用新版本目录和新记录。当前学习主页及学习记录不由这个试样替代。
