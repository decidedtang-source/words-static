# 工作英语 · 静态词库

包含近期15批、1875条词汇，最新日期2026-10-29。GitHub Pages直接提供静态HTML/JS/词表，无服务器、账号、配对码或Cookie身份验证。

点击“开始学习”，想中文，再“显示释义”，选不认识/模糊/认识。默认每日新学20条，资料库存不等于必学量；可选择日期、搜索词库、勾选已读。显示释义会尝试读一次单词；默认仅选设备本地英文声音，没有声音仍可学习。手机没有本地声音时，可在记录与设置主动开启“手机兼容发音（可能联网）”：尝试其他英文声音或系统默认英文声音，朗读文本可能交给设备语音服务处理，不发送学习记录。若设备本身没有可用语音引擎，兼容模式也不能保证发声。

学习记录保存在当前浏览器的IndexedDB。网站更新词表不会清空进度。浏览器数据清理、无痕模式、设备更换可能导致记录不可用；请定期在“记录与设置”导出JSON。导出文件可交给助手分析，也可在另一浏览器导入；没有自动上传和跨设备同步。

导入采用事件编号去重。不同设备对同一个词形成分叉进度时拒绝合并，保留当前记录，让用户将两份文件交给助手整理，不猜测覆盖。相同备份重复导入不会重复计数。导入前建议先导出当前记录。

评分由ts-fsrs6.0.0计算：Again/Hard/Good对应三个按钮；保留率0.90，学习/重学1m与10m，关闭fuzz。保存通过本地数据库事务确认后才推进。撤销最近有效评分限60秒；已读不改变排期。认识比例不等于客观掌握率。

显示释义后先显示简短中文词义；语境解释、两组中英例句可分别展开。手机学习操作栏固定在底部，评分后下一张卡片回到顶部。个别原例存在概念问题时，在例句区标明原例提示。

## 更新词表

```text
npm ci
node scripts/update-vocabulary.mjs <词表目录的绝对路径>
npm test
npm run build
```

更新前必须为每个源日期准备 `content/YYYY-MM-DD.json`，以原ID为键，填写 `gloss` 和至少两组 `{en, zh}` 例句，第一条英文须逐字保留源例句。可用 `editorialNote` 标注源例的概念问题。新增日期也需先完成这一编辑文件；缺失文件、ID覆盖不全或例句不合格时更新会中止，不写入词表。

输入目录包含YYYY-MM-DD.entries.json。更新器读取全部日期，校验ID与字段，仅发布英文、音标、词性、中文、搭配、例句、难度和日期；省略内部来源链接、Notion/Drive标识及其他内部字段。原文件只读。相同来源ID保留，不能为了更新词义随意换ID。

提交到main后GitHub Actions重新构建Pages。构建产物仅静态文件，不包含任何浏览器学习数据。首次注册Pages需要将来源设为GitHub Actions。

## 本地验证

`npm test`运行模型测试；`npm run build`构建；`npm run test:browser`运行隔离Chromium测试。可通过CHROMIUM_PATH指定已安装的浏览器可执行文件。测试本地HTTP服务只用于开发验证，访问已发布网页不需要运行它。

网页词汇资料公开可读取，noindex仅用于提示搜索引擎不索引，不是访问权限。学习进度不会主动发送到GitHub或分析服务。此版本不承诺完整离线缓存；离线时已打开页面可继续本地操作，但重新打开需能加载网页资源。
